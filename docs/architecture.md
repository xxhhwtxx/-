# 核心模块设计

## 1. 用户与权限

- 角色：
  - 管理员：全局配置、库存管理、审计查看
  - 渠道：下单、查单、接收回执
  - 终端用户：仅查看与自身相关的订单和结果（可选）
- 权限模型：RBAC + 渠道数据隔离（tenant_id）

## 2. 卡库存管理

- 卡池（按产品、面值、币种、渠道策略分组）
- 卡状态：
  - NEW（新入库）
  - AVAILABLE（可分配）
  - LOCKED（已锁定待发放）
  - ISSUED（已发放）
  - EXPIRED（过期）
  - DISABLED（禁用）
- 锁定机制：
  - 发卡前原子锁卡（带锁过期时间）
  - 发卡失败自动释放或人工处理

## 3. 发卡引擎

- 输入：订单、渠道、产品、策略
- 规则匹配：优先级（渠道专属池 > 公共池）、库存策略（FIFO/LIFO）
- 并发控制：
  - 库存扣减使用事务 + 行级锁/乐观锁
  - 同订单幂等键去重
- 输出：发卡成功/失败及失败原因码

## 4. 订单与履约

- 订单状态：
  - CREATED
  - PAID
  - PROCESSING
  - SUCCESS
  - FAILED
  - CANCELED
- 履约状态与订单状态解耦，支持异步补偿与重试

## 5. 通知与回执

- 通知通道：Webhook（优先）、短信/邮件（可选）
- 回执策略：
  - 成功回执：发卡结果、掩码卡信息、追踪号
  - 失败回执：原因码、可重试标识
  - 签名与重试机制（指数退避）
