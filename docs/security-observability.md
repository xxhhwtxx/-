# 安全、风控与可观测性

## 1. 安全设计

- 卡密存储：
  - 敏感字段加密存储（如 card_secret）
  - 输出给渠道前按策略脱敏
- 传输安全：
  - 全站 HTTPS
  - API 签名（HMAC-SHA256）+ 时间戳 + nonce 防重放
- 权限隔离：
  - RBAC + tenant_id 数据隔离
  - 管理操作二次确认（可选）

## 2. 风控设计

- 频控：
  - 渠道级 QPS 限流
  - 用户级请求频率阈值
- 黑名单：
  - 渠道、IP、设备标识黑名单
- 风险事件：
  - 连续失败、异常地域、异常并发写入 risk_events

## 3. 审计与告警

- 审计日志：
  - 覆盖卡状态变更、订单状态变更、权限变更
- 告警：
  - 发卡失败率异常
  - 锁卡超时积压
  - 回执连续失败

## 4. 可观测性

- 日志：结构化日志（request_id、trace_id、channel_id、order_id）
- 指标：
  - 发卡成功率
  - 平均履约时延
  - 可用库存水位
  - 回执重试次数
- 链路追踪：下单→锁卡→发卡→回执全链路
