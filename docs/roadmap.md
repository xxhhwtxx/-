# 分阶段交付计划

## Phase 1：MVP（最小可用）

- 库存管理：
  - 卡池创建
  - 卡密入库
  - 库存查询
- 发卡 API：
  - 创建订单
  - 触发发卡
  - 查询订单结果
- 订单记录：
  - 订单状态流转
  - 发卡记录落库
  - 基础审计日志

## Phase 2：能力增强

- 风控能力：
  - 限流、黑名单、风险评分基础规则
- 管理后台：
  - 库存视图
  - 订单检索
  - 手动补偿入口
- 渠道接入：
  - 多渠道鉴权
  - Webhook 回执重试策略

## Phase 3：运营自动化

- 自动补货与库存阈值告警
- 失败订单自动化补偿策略
- 运营报表与策略看板
